Bantuan & Panduan Fitur SQLGen

✨ Fitur-Fitur Utama Baru:

  • Ekspor Teks (.txt), .sql, & .md: Simpan hasil kueri sesuai kebutuhan dokumentasi atau skrip database.
  • Penyimpanan Otomatis (Auto-Save): Perubahan disimpan secara instan di browser (`localStorage`). Halaman aman untuk di-refresh.
  • Tautan Berbagi (Shareable Link): Klik tombol Bagikan untuk menghasilkan URL instan berisi state kueri Anda tanpa server backend.
  • Smart Sort vs Manual Order: Anda bisa membiarkan sistem menyusun urutan logis SQL, atau menggunakan tombol panah atas/bawah di tiap baris untuk kustomisasi manual.
  • Format Output: Pilih antara mode rapi bertingkat (Pretty) atau format satu baris (Inline).

⌨️ Pintasan Papan Ketik (Keyboard Shortcuts):

Kompilasi Kueri: Ctrl / Cmd + Enter
Tambah Baris Baru: Tekan Enter di input

Tips Pembuatan Kueri:

Jika input klausa SELECT dibiarkan kosong, sistem akan otomatis mengisinya dengan tanda bintang (*).
